# Question Type Schemas

This directory contains schema definitions and validation functions for all supported question types in the Skoolific V2 AI Test Generator.

## Overview

The AI Test Generator supports 9 different question types, each with its own schema definition and validation rules. These schemas ensure that questions generated by the Gemini API or created manually conform to the expected structure.

## Supported Question Types

1. **Multiple Choice** (`multiple_choice`)
2. **True/False** (`true_false`)
3. **Multiple True/False** (`multiple_true_false`)
4. **Matching** (`matching`)
5. **Numeric Response** (`numeric`)
6. **Fill-in-the-Blank** (`fill_blank`)
7. **Short Answer** (`short_answer`)
8. **Essay/Open-Ended** (`essay`)
9. **Transformation/Error Correction** (`transformation`)

## Usage

### Importing the Module

```javascript
const {
  validateQuestion,
  validateExam,
  getSupportedQuestionTypes,
  isQuestionTypeSupported,
  getQuestionSchema
} = require('./schemas/questionTypes');
```

### Validating a Single Question

```javascript
const question = {
  id: 1,
  type: 'multiple_choice',
  question: 'What is the capital of Ethiopia?',
  options: ['Addis Ababa', 'Nairobi', 'Kampala', 'Khartoum'],
  correctAnswer: 'Addis Ababa',
  marks: 2,
  explanation: 'Addis Ababa is the capital and largest city of Ethiopia.'
};

const validation = validateQuestion(question);

if (validation.valid) {
  console.log('Question is valid!');
} else {
  console.log('Validation errors:', validation.errors);
}
```

### Validating an Entire Exam

```javascript
const exam = {
  title: 'Math Test',
  totalMarks: 10,
  questions: [
    // ... array of question objects
  ]
};

const examValidation = validateExam(exam);

if (examValidation.valid) {
  console.log('Exam is valid!');
} else {
  console.log('Exam errors:', examValidation.errors);
  console.log('Question-specific errors:', examValidation.questionErrors);
}
```

### Checking Question Type Support

```javascript
// Get all supported types
const types = getSupportedQuestionTypes();
console.log(types); // ['multiple_choice', 'true_false', ...]

// Check if a specific type is supported
if (isQuestionTypeSupported('multiple_choice')) {
  console.log('Multiple choice questions are supported');
}

// Get schema for a specific type
const schema = getQuestionSchema('multiple_choice');
console.log(schema); // Returns the schema object
```

## Question Type Details

### 1. Multiple Choice

**Required Fields:**
- `id` (number): Question identifier
- `type` (string): Must be "multiple_choice"
- `question` (string): The question text (10-2000 characters)
- `options` (array): 2-6 answer options
- `correctAnswer` (string): Must match one of the options
- `marks` (number): 0.5-100
- `explanation` (string): Explanation for correct answer (10-1000 characters)

**Example:**
```javascript
{
  id: 1,
  type: "multiple_choice",
  question: "What is the capital of Ethiopia?",
  options: ["Addis Ababa", "Nairobi", "Kampala", "Khartoum"],
  correctAnswer: "Addis Ababa",
  marks: 2,
  explanation: "Addis Ababa is the capital and largest city of Ethiopia."
}
```

### 2. True/False

**Required Fields:**
- `id`, `type`, `question`, `marks`, `explanation` (same as base)
- `options` (array): Must be exactly ["True", "False"]
- `correctAnswer` (string): Either "True" or "False"

**Example:**
```javascript
{
  id: 2,
  type: "true_false",
  question: "Ethiopia uses the Gregorian calendar.",
  options: ["True", "False"],
  correctAnswer: "False",
  marks: 1,
  explanation: "Ethiopia uses the Ethiopian calendar."
}
```

### 3. Multiple True/False

**Required Fields:**
- `id`, `type`, `question`, `marks`, `explanation` (same as base)
- `statements` (array): 2-10 statements to evaluate
- `correctAnswers` (array): Boolean values for each statement

**Example:**
```javascript
{
  id: 3,
  type: "multiple_true_false",
  question: "Evaluate the following statements:",
  statements: [
    "Ethiopia is landlocked",
    "The Blue Nile originates in Ethiopia",
    "Ethiopia is in West Africa"
  ],
  correctAnswers: [true, true, false],
  marks: 3,
  explanation: "Ethiopia is landlocked (True), Blue Nile originates from Lake Tana (True), but Ethiopia is in East Africa (False)."
}
```

### 4. Matching

**Required Fields:**
- `id`, `type`, `question`, `marks`, `explanation` (same as base)
- `leftColumn` (array): 2-10 items
- `rightColumn` (array): 2-10 items (must match leftColumn length)
- `correctMatches` (array): Array of {left, right} pairs

**Example:**
```javascript
{
  id: 4,
  type: "matching",
  question: "Match the emperors with their achievements:",
  leftColumn: ["Haile Selassie", "Menelik II", "Tewodros II"],
  rightColumn: ["Modernized Ethiopia", "Defeated Italy at Adwa", "United Ethiopia"],
  correctMatches: [
    { left: "Haile Selassie", right: "Modernized Ethiopia" },
    { left: "Menelik II", right: "Defeated Italy at Adwa" },
    { left: "Tewodros II", right: "United Ethiopia" }
  ],
  marks: 3,
  explanation: "Historical achievements of Ethiopian emperors."
}
```

### 5. Numeric Response

**Required Fields:**
- `id`, `type`, `question`, `marks`, `explanation` (same as base)
- `correctAnswer` (number or string): The correct numeric answer

**Optional Fields:**
- `unit` (string): Unit of measurement (e.g., "cm²", "kg")
- `acceptableRange` (object): {min, max} for rounding tolerance

**Example:**
```javascript
{
  id: 5,
  type: "numeric",
  question: "Calculate the area of a rectangle with length 12 cm and width 8 cm.",
  correctAnswer: "96",
  unit: "cm²",
  acceptableRange: { min: 95.5, max: 96.5 },
  marks: 2,
  explanation: "Area = length × width = 12 × 8 = 96 cm²"
}
```

### 6. Fill-in-the-Blank

**Required Fields:**
- `id`, `type`, `marks`, `explanation` (same as base)
- `question` (string): Must contain "\_\_\_\_\_" to indicate blanks
- `correctAnswers` (array): 1-10 correct answers (in order)

**Example:**
```javascript
{
  id: 6,
  type: "fill_blank",
  question: "The capital of Ethiopia is _____ and it is located at approximately _____ meters elevation.",
  correctAnswers: ["Addis Ababa", "2400"],
  marks: 2,
  explanation: "Addis Ababa is at about 2,400 meters above sea level."
}
```

### 7. Short Answer

**Required Fields:**
- `id`, `type`, `question`, `marks`, `explanation` (same as base)
- `modelAnswer` (string): Model answer for teacher reference (20-1000 characters)
- `keyPoints` (array): 2-10 key points that should be included

**Example:**
```javascript
{
  id: 7,
  type: "short_answer",
  question: "Explain the significance of the Battle of Adwa.",
  modelAnswer: "The Battle of Adwa was a decisive Ethiopian victory against Italy that preserved Ethiopian independence.",
  keyPoints: [
    "Decisive Ethiopian victory",
    "Defeated Italian colonization",
    "Preserved independence"
  ],
  marks: 5,
  explanation: "Should mention victory, independence, and African resistance."
}
```

### 8. Essay/Open-Ended

**Required Fields:**
- `id`, `type`, `question`, `marks`, `explanation` (same as base)
- `modelAnswer` (string): Model answer (50-5000 characters)
- `rubric` (array): 2-10 grading criteria with points

**Example:**
```javascript
{
  id: 8,
  type: "essay",
  question: "Discuss the impact of the Ethiopian calendar on modern society.",
  modelAnswer: "The Ethiopian calendar has both cultural significance and practical implications...",
  rubric: [
    { criterion: "Understanding of calendar", points: 3 },
    { criterion: "Analysis of impact", points: 3 },
    { criterion: "Organization", points: 2 }
  ],
  marks: 8,
  explanation: "Should demonstrate understanding and provide examples."
}
```

**Note:** The sum of rubric points must equal the question marks.

### 9. Transformation/Error Correction

**Required Fields:**
- `id`, `type`, `question`, `marks`, `explanation` (same as base)
- `originalText` (string): Text to be transformed/corrected (5-1000 characters)
- `correctTransformation` (string): Correct version (5-1000 characters)

**Example:**
```javascript
{
  id: 9,
  type: "transformation",
  question: "Correct the grammatical errors in the following sentence:",
  originalText: "The students was going to school.",
  correctTransformation: "The students were going to school.",
  marks: 2,
  explanation: "Subject-verb agreement: students (plural) requires were."
}
```

## Validation Rules

### Common Validations

- **Required fields**: All base fields (id, type, question, marks, explanation) are required
- **Question length**: 10-2000 characters
- **Explanation length**: 10-1000 characters
- **Marks range**: 0.5-100

### Type-Specific Validations

- **Multiple Choice**: `correctAnswer` must be one of the `options`
- **Matching**: `leftColumn` and `rightColumn` must have equal length
- **Multiple True/False**: `correctAnswers` array must match `statements` array length
- **Fill-in-the-Blank**: Question must contain "\_\_\_\_\_" placeholder
- **Essay**: Sum of rubric points must equal question marks

## Integration with Gemini API

When integrating with the Gemini API:

1. **Generate questions** using the AI Test Generator prompt
2. **Parse the JSON response** from Gemini
3. **Validate each question** using `validateQuestion()`
4. **Validate the entire exam** using `validateExam()`
5. **Display validation errors** to the teacher if any
6. **Allow teacher to edit/fix** invalid questions
7. **Re-validate** before saving to database

Example integration:

```javascript
const geminiResponse = await generateExamWithGemini(examConfig);
const exam = JSON.parse(geminiResponse);

// Validate the exam
const validation = validateExam(exam);

if (!validation.valid) {
  // Show errors to teacher
  return {
    success: false,
    errors: validation.errors,
    questionErrors: validation.questionErrors,
    exam: exam // Return exam for editing
  };
}

// Exam is valid, proceed to save
await saveExamToDatabase(exam);
```

## Error Handling

Validation functions return detailed error messages:

```javascript
{
  valid: false,
  errors: [
    "Field 'options' is required for multiple_choice questions",
    "Field 'marks' must be at least 0.5"
  ]
}
```

For exam validation:

```javascript
{
  valid: false,
  errors: [
    "Question 1 has validation errors",
    "Total marks mismatch: declared 100, calculated 95"
  ],
  questionErrors: {
    question_1: [
      "Field 'options' is required for multiple_choice questions"
    ]
  }
}
```

## Best Practices

1. **Always validate** questions before saving to database
2. **Provide clear error messages** to teachers when validation fails
3. **Allow editing** of invalid questions rather than rejecting entirely
4. **Re-validate** after any manual edits
5. **Log validation errors** for debugging and improvement
6. **Use type-specific schemas** when creating manual questions
7. **Test with edge cases** (minimum/maximum values, empty arrays, etc.)
